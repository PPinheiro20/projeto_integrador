# 🎮 Coleção de Jogos

## 📌 Tema

Aplicativo mobile para **organização e acompanhamento de uma coleção de jogos**.

## 💡 Sobre o aplicativo

O aplicativo permite que o usuário cadastre jogos em sua coleção e acompanhe o progresso de cada um através de três status:

- **Quero jogar**
- **Jogando**
- **Concluído**

Também é possível editar e excluir jogos cadastrados, além de limpar toda a coleção.

Os dados são armazenados localmente utilizando **AsyncStorage**, permitindo que a coleção continue salva mesmo após fechar o aplicativo.

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- AsyncStorage
